# HTML + CSS 练习题

> 对应笔记：《JavaWeb/笔记/01-HTML+CSS知识点.md》
> 每个知识点 2~3 题，共 12 个文件，全部在 VS Code 里练。
> ⭐ = 后端开发重点（3 题），其余为基础（2 题）。

## 怎么用

1. 用 VS Code 打开 `excise_html_css` 这个文件夹（File → Open Folder）。
2. 每个 `.html` 文件里只有**骨架 + TODO 题目 + 提示**，**没有答案**，答案要你自己写。
3. 写完后保存，右键文件 → **Open with Live Server**（装了 Live Server 插件），或者直接双击用浏览器打开。
4. 对照题目里的「目标效果」检查自己做对没有；卡住了再回头看笔记。
