## 一、JS 基础

### 1. 引入方式（01）
- **内部脚本**：`<script> ... </script>`
- **外部脚本**：`<script src="xx.js"></script>`

### 2. 基础语法（02）⭐
| 关键字 | 作用 | 能否重新赋值 |
|--------|------|--------------|
| `let`  | 声明变量 | 能，且类型可变 |
| `const`| 声明常量 | 不能 |

- 输出方式：`alert()` 弹窗、`console.log()` 控制台、`document.write()` 页面（少用）

### 3. 数据类型（03）⭐
- 基本类型：`number` / `boolean` / `string` / `null` / `undefined`
- `typeof` 运算符：返回类型名字符串
- ⚠️ **坑**：`typeof null` 结果是 `"object"`（历史遗留 bug）

### 4. 模板字符串（03）⭐
- 用反引号 `` ` `` 包裹，变量用 `${变量名}` 插入
- 例：`` `我是${name}, 今年${age}岁` ``

### 5. 函数（04）⭐⭐
| 写法 | 语法 | 说明 |
|------|------|------|
| 具名函数 | `function add(a,b){...}` | 最传统 |
| 匿名函数（函数表达式）| `let add = function(a,b){...}` | 赋值给变量 |
| 箭头函数 | `let add = (a,b) => {...}` | 简写，最常用 |

- ⚠️ **箭头函数 `this` 指向父级**，不在对象方法里乱用箭头函数
- 箭头函数简写：单参数可省 `()`；单行 `return` 可省 `{}` 和 `return`

### 6. 自定义对象 & JSON（05）⭐⭐
- 对象字面量：`let user = { name:'Tom', age:18 }`，属性之间用**逗号**隔开
- 方法简写：`sing(){...}`，方法内用 `this` 访问属性
- **JSON 转换**（前后端交互核心）：
  - `JSON.stringify(对象)` → 对象转 JSON 字符串
  - `JSON.parse(json字符串)` → JSON 字符串转对象

## 二、DOM 操作（06、07）⭐⭐

| API | 作用 | 返回值 |
|-----|------|--------|
| `document.querySelector('选择器')` | 获取第一个匹配元素 | 单个元素 |
| `document.querySelectorAll('选择器')` | 获取所有匹配元素 | NodeList（可遍历） |

- 改内容：`元素.innerHTML = '...'`
- 改样式：`元素.style.backgroundColor = '#xxx'`

## 三、事件（08、09、10、11）⭐⭐

- **推荐写法**：`元素.addEventListener('事件名', 回调函数)` —— 可多次绑定，不覆盖
- **早期写法**：`元素.onclick = 函数` —— 多次绑定会覆盖，仅了解

### 常见事件
| 事件 | 触发时机 |
|------|----------|
| `click` | 点击 |
| `mouseenter` / `mouseleave` | 鼠标移入 / 移出 |
| `keydown` / `keyup` | 键盘按下 / 抬起 |
| `blur` / `focus` | 失去 / 获得焦点 |
| `input` | 输入时 |
| `submit` | 表单提交 |

### 模块化 JS（11）
- `<script type="module">` + `import ... from ...` / `export`

## 四、Vue3（⭐⭐⭐ 重点，后端项目必会）

### 4.1 Vue 解决什么问题？
- 之前操作页面（练习四、五）是**命令式**：手动 `querySelector` 拿元素 → 手动 `innerHTML` 改 → 手动 `addEventListener` 绑事件，每一步都自己写。
- Vue 是**声明式**：你只把数据放进 `data`，模板里用 `{{ }}` 引用，Vue 自动渲染；**数据一变，页面自动更新**。这叫「数据驱动视图」。

### 4.2 一个 Vue 应用的三件套
```
① 挂载点  → HTML 里一个带 id 的标签：<div id="app">
② 数据    → data() { return { ... } }
③ 挂载    → createApp({...}).mount('#app')
```
- 三者靠 `#app` 这个 id 对上号，缺一不可。

### 4.3 插值表达式 `{{ }}` ⭐
- 作用：把 `data` 里的数据显示到页面的**文本内容**里。
- 里面能写**简单的 JS 表达式**：
  - `{{ count + 1 }}`（运算）
  - `{{ message.toUpperCase() }}`（调方法）
  - `{{ a ? '男' : '女' }}`（三元）
- ⚠️ **只能放在标签的文本内容里，不能放在标签属性里**（属性要用 v-bind）。

### 4.4 methods 和 this ⭐
- `methods` 是放「方法」的地方，模板里 `@click="方法名"` 就会在点击时调用它。
- 方法里用 `this` 访问数据：`this.count` 就是 `data` 里的 `count`。
- `this` 指向当前这个 Vue 应用实例。

### 4.5 六大核心指令 ⭐⭐

| 指令 | 作用 | 简写 / 说明 |
|------|------|-------------|
| `v-model` | 双向绑定表单数据 | 无，只用于 input/select 等表单元素 |
| `v-for` | 列表渲染（循环数组） | `v-for="(item, index) in list"` + `:key` |
| `v-if` / `v-else-if` / `v-else` | 条件渲染（增删 DOM） | 无 |
| `v-show` | 条件显示（切 display） | 无 |
| `v-bind:属性` | 动态绑定属性 | 简写 `:属性`，如 `:src` |
| `v-on:事件` | 绑定事件 | 简写 `@事件`，如 `@click` |

#### 逐个说明
- **v-model**：双向绑定。输入框一改，数据改；数据一改，输入框也改。一行顶替以前 `addEventListener('input')` 的手动同步。
- **v-for**：循环数组，每个元素渲染一份标签。`item` 是当前元素，`index` 是下标（从 0 开始）。`:key` 必须写，是每条的唯一标识。
- **v-if vs v-show**：
  - `v-if`：false 时把元素**从 DOM 删除**（频繁切换较耗性能）
  - `v-show`：false 时加 `display:none`（元素还在，切换更快）
  - 频繁切换用 v-show，一次性判断用 v-if。
- **v-bind**：给属性绑定数据。`{{ }}` 不能用在属性里，属性要用 `v-bind` / `:`。
- **v-on**：绑定事件，`@click="方法名"` 调用 methods 里的方法。

### 4.6 Vue 快速入门模板（背下来）
```html
<div id="app">
  <h1>{{ message }}</h1>
  <button @click="doSomething">按钮</button>
</div>

<script type="module">
  import { createApp } from './js/vue.esm-browser.js';
  createApp({
    data() { return { message: 'Hello' } },  // 数据
    methods: { doSomething() { ... } },      // 方法
    mounted() { ... }                        // 生命周期钩子（进阶）
  }).mount('#app');
</script>
```

## 五、Ajax + Axios（14、15、16）⭐⭐⭐

### 通用写法
```js
axios({ url:'...', method:'GET', data:'...' })
  .then(result => { console.log(result.data); })
  .catch(err => { console.log(err); });
```

### 请求方式别名
- `axios.get(url)`
- `axios.post(url, data)`

### async / await（16）
- `async` 方法里用 `await axios.get(...)` 直接拿结果，代码更直观
- `mounted()` 钩子：页面加载完成后自动发请求初始化数据

### Vue + Axios 结合套路
1. `data()` 里定义空列表（如 `empList: []`）
2. `methods` 里写 `async search()`，`await` 拿数据后赋值 `this.empList = result.data.data`
3. `mounted()` 里调用 `this.search()`
