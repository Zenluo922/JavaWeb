## 使用方式

- **01~05**：直接用浏览器打开 `.html` 文件，结果看**控制台**（F12 → Console）
- **06 系列**：依赖 `./js/vue.esm-browser.js`（已放入 `js/` 目录），建议**从 1 到 6 按顺序做**，每个文件做完再开下一个
- **07**：依赖 `./js/axios.js`，请求的是 mock 接口，**需要联网**
